# Помощник мастера D&D — MCP-сервер

MCP-сервер, который даёт языковой модели доступ к русскоязычному справочнику
настольной игры Dungeons & Dragons 5 — сайту [dnd.su](https://dnd.su).

Данные предоставляются по запросу. Хостинг не нужен: сервер запускается локально
у вас на компьютере и работает, пока вы им пользуетесь.

## Возможности

| Инструмент | Что делает |
|---|---|
| `search_spells(query, level, school, ritual)` / `get_spell(name)` | поиск и полное описание заклинаний (с фильтрами по уровню, школе, ритуалу) |
| `search_monsters(query, cr, size, creature_type, environment)` / `get_monster(name)` | поиск и полный блок монстра (с фильтрами по ПО, размеру, виду, местности) |
| `search_items(query, rarity, item_type)` / `get_item(name)` | поиск и описание магических предметов (с фильтрами по редкости и типу) |
| `search_classes(query)` / `get_class(name, section)` | поиск и статья о классе (уровни, умения, подклассы) |
| `search_races(query)` / `get_race(name, section)` | поиск и статья о расе |
| `search_backgrounds(query)` / `get_background(name, section)` | поиск и статья о предыстории |
| `search_feats(query)` / `get_feat(name, section)` | поиск и описание черты |
| `list_rules(section)` | каталог статей по правилам (`all`, `mechanics`, `inventory`, `newbie`) |
| `search_rules(query)` | поиск статей по правилам, **включая содержимое** (например «алебарда», «засада») |
| `get_rules(query, section)` | текст статьи по правилам (по названию, теме из содержимого или URL) |
| `plan_encounter(party, monsters)` | сложность боевой сцены по DMG: опыт, множитель, пороги, сложность (Легко/Средне/Сложно/Смертельно), опыт на персонажа |
| `generate_loot(category, tier)` | случайная добыча: монеты, камни, искусство, безделушки, сокровищница, свитки, магические предметы |
| `roll_dice(notation)` | бросок кубов, например `2d6+3` или `3d8+1d4-2` |

Искать можно и по-русски («огненный шар»), и по-английски («fireball»).

У длинных статей (в первую очередь классы и расы) есть необязательный параметр
`section` — он возвращает только нужный раздел, например
`get_class("паладин", section="клятва мести")` или
`get_class("варвар", section="ярость")`. Если раздел не найден, инструмент вернёт
список доступных разделов статьи.

Поиск по правилам (`search_rules` и `get_rules`) работает не только по названиям
статей, но и по их содержимому: `get_rules("алебарда")` найдёт статью
«Оружие [Arms]», внутри которой есть таблица урона оружия. Если запросу
соответствует несколько статей, инструмент вернёт список — уточните запрос,
назовите статью точнее или передайте её URL.

## Быстрый старт

Нужен Python 3.10 или новее. Установка один раз:

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Запуск сервера вручную (для проверки):

```powershell
.venv\Scripts\python server.py
```

Сервер работает по протоколу **stdio** — сам по себе он ничего не печатает,
он отвечает клиенту (Claude Desktop, Cursor, Kilo и т.п.), который его запустил.

## Подключение к клиенту

В конфиге клиента укажите путь к `server.py` и к python из виртуального
окружения. Пути лучше писать абсолютные.

### Claude Desktop

Файл `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "dnd-master-helper": {
      "command": "C:\\путь\\к\\dnd-master-helper\\.venv\\Scripts\\python.exe",
      "args": ["C:\\путь\\к\\dnd-master-helper\\server.py"]
    }
  }
}
```

### Cursor

Файл `.cursor/mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "dnd-master-helper": {
      "command": "C:\\путь\\к\\dnd-master-helper\\.venv\\Scripts\\python.exe",
      "args": ["C:\\путь\\к\\dnd-master-helper\\server.py"]
    }
  }
}
```

### Kilo

Создайте файл `kilo.json` в корне проекта (он не входит в репозиторий — это
локальная настройка) с подключением сервера:

```json
{
  "mcp": {
    "dnd-master-helper": {
      "type": "local",
      "command": ["...\\.venv\\Scripts\\python.exe", "...\\server.py"],
      "enabled": true,
      "timeout": 30000
    }
  }
}
```

После изменения конфига перезапустите сессию Kilo (или включите сервер через
палитру команд, пункт `/mcps`). Инструменты сервера появятся у агента с
префиксом `dnd-master-helper_`, например `dnd-master-helper_get_spell`.
Разрешения на них настраиваются в разделе `permission` конфига.

После подключения попробуйте спросить: «Дай полное описание заклинания огненный
шар» или «Найди взрослого белого дракона и покажи его блок характеристик».

## Структура проекта

```
server.py        — MCP-сервер (инструменты)
scraper.py       — работа с данными dnd.su
requirements.txt — зависимости
dnd_cache.db     — локальный кэш страниц (создаётся автоматически, в репозиторий не входит)
```

## Примечания

- Инструменты задуманы для точечных обращений — не запрашивайте весь справочник
  одним запросом.
- Страницы кэшируются в `dnd_cache.db` на 24 часа — повторные запросы к одним и
  тем же сущностям почти мгновенны и не нагружают сайт-источник. Эндпоинты
  случайной добычи не кэшируются, чтобы каждый бросок был новым.
- Права на материалы D&D принадлежат Wizards of the Coast; dnd.su публикует их
  «для ознакомления». Этот сервер отдаёт пользователю ровно то, что он и так
  мог бы открыть в браузере, и указывает источник.
- Если сайт-источник изменится, сервер может перестать работать.
